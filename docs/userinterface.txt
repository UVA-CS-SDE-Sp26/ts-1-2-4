User Interface Plan (Team A)

Responsibility
- Define valid command‑line inputs and outputs.
- Display file lists, file contents, and error messages.
- Do not read files directly or perform deciphering.

Inputs
- CLI arguments: none, [fileNumber], or [fileNumber] [keyPath].

Outputs
- Numbered list of available files.
- File contents (plain or deciphered).
- User‑friendly error messages.

Interface (proposed)
- class TopSecret
  - main(String[] args)
  - ProgramController controller
  

Behavior
- If no args: call ProgramController.listFiles() and print result.
- If one arg: parse file number, call ProgramController.showFile(index, empty).
- If two args: parse number and key path, call ProgramController.showFile(index, keyPath).
- Print output and exit.

Error Handling
- If arg count invalid: print "Too many arguments".
- If file number invalid format: print "Invalid file number".
- If file number out of range: print "File number not found".
- If file cannot be read: print "Unable to read file".
- If cipher key invalid or missing: print "Invalid key".

Testing Ideas (TDD)
- No args prints a numbered list.
- One arg prints selected file content.
- Two args uses alternate key path.
- Invalid number format prints error.
- Too many args prints error.
