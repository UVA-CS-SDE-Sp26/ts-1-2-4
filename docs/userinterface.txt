userinterface.txt

Define the command line interface for the Top-secret program. This document describes valid commands, inputs, outputs, and error handling. 


Start of program:
	Ask User for 
------------------------------------------------------------
case1: No Arguments
------------------------------------------------------------
	Input: null

	Command: 
		java topsecret
	Output: All files ( In data folder )
	Behavior: 
		- Display a numbered list of all available text files.
		- Each file on it's own line
		- List is ordered in ascending order
	Example Output:	
		01 file1.txt
		02 file2.txt
		03 file3.txt
-------------------------------------------------------------
case2: One Argument (File Number)
-------------------------------------------------------------
	input: number representing specific text file
	Output: Input number for that data file
	Behavior:
		- Display contents of the file corresponding to the given number.
		- Uses default cipher key if deciphering is required
	Example Output:
		java topsecret 01
-------------------------------------------------------------
case3: Two Arguments (File Number + Alternate Key)
-------------------------------------------------------------
	input: number and alternate key
	Output: 
	Behavior: 
		- Display contents of specific file
		- Use the provided cipher key instead of default key
	Example Output: 	
		java topsecret 01 mykey.txt"
-------------------------------------------------------------
Error Handling: 
-------------------------------------------------------------
	Output: Let user know that that error has occurred. 

	Handled errors are:
		- Invalid file number format
		- File number not found in list
		- Too many command-line arguments
		- File cannot be found
		- File can not be deciphered 

	Example:
		Error: Invalid File Number
